# Visualization of the movement of a magnetic Bloch point through a nanotrack as the result of an applied magnetic field.

## Melanie Wiegand
## CS410 Science Visualization, Spring 2026 w/ Prof. Hank Childs
## 5/11/2026

This data is from the "Lx_200_Ly_100_hb_14_ht_10_lmax_3_Hy_0.05" folder in the below link, which depicts a 200x100 nanometer nanotrack affected by an applied magnetic field of 0.05 Tesla.

My video shows the net magnetization of the ferromagnetic material (isosurfaced to ~1, but I thought the color spectrum looked cool so I kept the tiny fluctuations :p)

I also depict a contour displaying the location of the Bloch point (a magnetic singularity with zero magnetic field but with azimuthal, vortex-like magnetization surrounding it).

I found this dataset while looking for interesting data relating to the work I do in my electron microscopy lab, where I study nanoscale magnetic textures like skyrmions. I thought this application of a magnetic field to the nanotrack produced some really cool patterns, and was informative about how nanotracks actually work to manipulate skyrmions for use in data storage.

I did not create any scripts when making this animation, and instead used VisIt's keyframe feature. A screenshot of the keyframe window is attached.

Source: Ryan Pepper, Marijan Beg, & Hans Fangohr. (2020). Dataset for "Field-driven Bloch Point Motion in Chiral Systems" (v1.0.0) [Data set]. Zenodo. https://doi.org/10.5281/zenodo.4016634
